# M2.1 · Đối chứng chat và API cho tác vụ văn bản

**Đạt trên phiên Kaggle 373506240.** Proxy local ở `127.0.0.1:8001`, worker instance `3fb3f56d149946b4827a82dd9bce48f0`, Qwen Q4_K_M với context 4096 trên hai Tesla T4. Client đối chứng dùng Python 3.12 trong `myenv` và `urllib.request`. Ca GUI dùng Firefox 159.0.1 headless với hồ sơ thử riêng.

## Tác vụ và tiêu chí

Dùng ghi chú họp giả lập bằng tiếng Việt chứa hai đầu việc và một chi tiết ngoài danh sách. Mỗi đầu việc có người phụ trách, việc và hạn. Chấm lượt đầu theo sáu dữ kiện cần trích xuất. Lượt tiếp theo hỏi ai phụ trách việc thứ hai và hạn là ngày nào. Kiểm tra câu trả lời chứa đúng người và hạn. Bảng dưới chỉ lưu cấu trúc request, loại phản hồi và kết quả kiểm tra.

| Client và thứ tự | Route | Trường và tùy chọn gửi đi | Phản hồi thực tế |
|---|---|---|---|
| Python 1 | `GET /ready` | Không có body | HTTP 200, `state=ready`, đúng instance, hai GPU và context 4096. Chưa có trường ước tính thời gian phiên còn lại. |
| Python 2 | `GET /v1/models` | Không có body | HTTP 200, một model với ID là đường dẫn GGUF. Alias `qwen-local` chưa xuất hiện. |
| Python 3 | `POST /v1/chat/completions` | `model` từ danh sách, `messages` gồm một lượt user, `stream=false`, `max_tokens=512`, `temperature=0` | HTTP 200, `application/json`, `finish_reason=stop`, usage 58 token prompt và 167 token sinh. Đủ sáu dữ kiện. |
| Firefox 1 | `GET /` rồi `GET /ready` | GUI tải trang và kiểm tra worker | GUI hiển thị `Ready`. Fetch lúc khởi động chỉ gọi `/ready`. |
| Firefox 2 | `POST /v1/chat/completions` | `messages` gồm một lượt user, `stream=true`, `stream_options.include_usage=true`, `max_tokens=512`. Mỗi message gồm `role` và `content`. | HTTP 200, `text/event-stream`, có `[DONE]`, `finish_reason=stop`. Usage 58 token prompt và 179 token sinh. Đủ sáu dữ kiện. |
| Firefox 3 | `POST /v1/chat/completions` | Cùng các trường, gửi toàn bộ lịch sử với vai trò user → assistant → user. | HTTP 200, SSE có `[DONE]`, `finish_reason=stop`. Usage 114 token prompt và 64 token sinh. Trả đúng người phụ trách và hạn. |
| Firefox 4 | Tải lại `/` | Cùng hồ sơ và origin | GUI về `Ready` và mở lại transcript đã lưu. |

Hai lượt chat chạy tuần tự, mỗi lần bấm gửi ghi nhận một POST. GUI gửi yêu cầu với model mặc định của proxy. Các số token là usage của lượt kiểm tra, có thể chịu ảnh hưởng bởi prompt cache. Đây là ca đo hợp đồng và hành vi, phục vụ đối chứng cho các lượt tiếp theo.

## Tiêu chí hồi quy cho M2

- **M2.2:** giữ đường gọi bằng ID hiện tại và đường gọi GUI để trống trường `model`. Bổ sung kiểm tra alias với JSON và SSE.
- **M2.3:** chạy riêng ca hai POST chồng nhau và kiểm tra `503 worker_busy` kèm `Retry-After`.
- **M2.4:** giữ phản hồi `state` và `health` mà GUI đang đọc. Kiểm tra thêm các trạng thái lỗi và trường ước tính thời gian phiên.

Phiên WebDriver đã đóng. Hệ điều hành từ chối tín hiệu dừng tiến trình hỗ trợ geckodriver cuối phép thử. Các kiểm tra API, SSE và mở lại lịch sử đã hoàn tất trước bước này.
