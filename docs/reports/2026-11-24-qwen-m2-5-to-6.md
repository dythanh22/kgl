# M2.5–M2.6 · Ví dụ API và nghiệm thu qua hai VM

## M2.5 · Ví dụ dùng hằng ngày

Đã chạy các ví dụ trong [hướng dẫn API](../../examples/qwen35b-llama/API.md) từ `myenv`. Ca live dùng notebook Kaggle 373506240 và model alias `qwen-local`.

| Ca | Kết quả |
|---|---|
| curl | `/ready`, `/v1/models` và POST JSON thành công. Alias xuất hiện trong danh sách, Chat Completions trả `finish_reason=stop`. |
| Python | `action_items.py` trích xuất đúng người phụ trách, đầu việc và hạn của hai đầu việc trong cả JSON và SSE. |
| Bearer key | Proxy thử riêng dùng worker thật, chấp nhận key đúng và trả 401 khi thiếu hoặc sai key. Model ID sai trả 400. |
| SSE gián đoạn | Máy chủ thử gửi một chunk rồi đóng kết nối trước `[DONE]`. Python giữ phần đã in, báo lỗi và thoát mã 1. |

## M2.6 · So sánh trước và sau đổi VM

**Đạt.** Notebook 373520239 có hai Tesla T4 và thư mục build ban đầu chưa tồn tại. `ready.py` khôi phục từ dataset và đưa worker về ready trong 204,341 giây, gồm cả thời gian nạp model. `proxy.py` chuyển cổng 8001 sang instance mới.

| Ca | Trước đổi VM | Sau đổi VM |
|---|---|---|
| Notebook và worker | 373506240, instance `3fb3f56d149946b4827a82dd9bce48f0` | 373520239, instance `224011a875204c1aa692ea5cfb498d0b` |
| Địa chỉ và model API | `http://127.0.0.1:8001/v1`, `qwen-local` | Cùng Base URL và alias. `curl` xác nhận `/ready`, `/v1/models` và JSON hoạt động. |
| Script Python 3.12 trong `myenv` | JSON và SSE đều trích xuất đúng hai đầu việc | Cùng script và dữ liệu, JSON và SSE đều trích xuất đúng hai đầu việc. |
| Firefox 159.0.1, hồ sơ thử riêng | Chat SSE trích xuất đúng hai đầu việc, câu hỏi tiếp nối trả đúng người và hạn. Hai lượt nhận `stop`, `[DONE]` và usage. Tải lại trang mở được lịch sử. | Cùng hồ sơ và origin. Mở được transcript cũ, chạy lại hai lượt và nhận đúng dữ kiện, `stop`, `[DONE]` và usage. |
| Stream bị cắt | Ca mô phỏng xác nhận giữ được đầu ra dở và báo lỗi | Lặp lại ca mô phỏng, giữ phần đã in và thoát mã 1. |

Ca đối chiếu dùng ghi chú giả lập tiếng Việt. Tiêu chí là giữ đúng hai bộ dữ kiện (người, việc, hạn) và ở lượt tiếp theo của chat, nhắc lại đúng người và hạn của đầu việc thứ hai. Nội dung nhập và key được lược khỏi báo cáo.

Trước khi đo, đã nạp mã proxy mới trên cổng 8001 với cùng worker. Chat trước đổi VM do Qwen thật sinh trong hồ sơ Firefox thử. Ca bearer sau đổi VM cũng xác nhận key đúng được chấp nhận, key thiếu hoặc sai trả 401 và model sai trả 400. Phiên WebDriver đã đóng ở cả hai lượt. Hệ điều hành từ chối tín hiệu dừng tiến trình hỗ trợ geckodriver sau khi phép thử hoàn tất.
